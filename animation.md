# Scaleoz animation files only

Use these two files in an existing Scaleoz website:

- `premium-motion.css`
- `scaleoz-animations.js`

Add this inside the `<head>` of your existing `index.html`:

```html
<link rel="stylesheet" href="premium-motion.css" />
```

Add this immediately before the closing `</body>` tag:

```html
<script src="scaleoz-animations.js"></script>
```

The animation files use the existing Scaleoz HTML class names, such as `.growth-visual`, `.chart-bars`, `.growth-arrow`, `.service-card`, `.project`, `.contact-card`, and `.reveal`.
